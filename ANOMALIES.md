# ANOMALIES

После импорта `review.csv` были обнаружены следующие проблемы.

## 1. Большинство компаний отсутствуют в основной базе

После сравнения таблицы `review_import` с основной таблицей `companies` по полю `id` оказалось, что из 207 записей только 6 присутствуют в основной базе.

Результат проверки:

- импортировано записей — 207;
- отсутствуют в основной базе — 201.

Проверка выполнялась сравнением `LEFT JOIN` по полю `id`.

---

## 2. Некорректные значения рейтинга

Обнаружены записи с неправильными значениями рейтинга.

Найдены следующие варианты:

- `N/A`;
- `4,5` (используется запятая вместо точки);
- `-3` (отрицательное значение);
- `7.2` (выходит за диапазон 0–5).

Проверка выполнялась регулярным выражением для допустимого формата рейтинга.

---

## 3. Некорректные номера телефонов

Обнаружены телефоны, не соответствующие формату

```
+7 (999) 999-99-99
```

Найдены значения:

- `8 (925) abc-12-34`;
- `+7`.

Проверка выполнялась регулярным выражением.

---

## 4. Некорректные значения города

При сравнении списка городов из `review.csv` со списком городов основной таблицы были обнаружены следующие проблемы:

- опечатка (`Санкат-Петербург`);
- название города на английском языке (`Moscow`);
- другой регистр (`москва`);
- пробел в конце строки (`Москва `);
- повреждённая кодировка (`РЎР°РЅ...`, `РњРѕ...`);
- пустое значение;
- вместо названия города записан адрес (`ул. Советская, д. 89, офис 43`).

Проверка выполнялась сравнением списка городов с основной таблицей `companies`.

---

## 5. Пустые значения

Во время анализа обнаружены записи:

- без сайта — 60;
- без телефона — 22;
- без рейтинга — 20.

Проверка выполнялась поиском пустых (`''`) и `NULL` значений.
